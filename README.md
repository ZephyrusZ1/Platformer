This game is a platformer game. You can attack the slimes by jumping on them, and if the slimes attack you, you will get knocked back. On the top left there is coin counter, it will reset after you die, reset through pause menu or changing level. On the top-center, there is health counter, which is pretty self explanatory on it's own and it also reset on the same condition like the coin counter. For now the coin still have no use because this game is still in prototype. The finish plate is the question mark block, it will bring you back to the level selection. There is a bit of visual lacking on the background which can make that when you fall, it seems like you are standing on the abyss instead of actually falling to your death. Some platforms here that goes up and down are actually designed to bring you down to world boundary which will instantly kill you so you actually get killed by the platform instead of dying for nothing.

Controls:
Left arrow and A - Move Left
Right arrow and D - Move Right
Space - Jump
ESC - Pause
